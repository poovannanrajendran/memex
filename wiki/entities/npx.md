## Overview
NPX is a package runner tool that comes with Node.js. It allows developers to execute Node.js package executables from their local project or a temporary cache without globally installing them.

## Role in this knowledge base
Mentioned as the command-line interface through which Agent Memory can be installed and run.

## Key facts
- It enables the installation and execution of Agent Memory with a single command.
