## Overview
The Gateway is the core component of OpenClaw responsible for hosting and managing multiple agents. It handles message routing, agent lifecycle, and inter-agent communication, acting as the central hub for all agent activity.

## Role in this knowledge base
The infrastructure that enables multi-agent functionality in OpenClaw.

## Key facts
- The Gateway can host one agent (default) or many agents side-by-side, managing their states and routing.
