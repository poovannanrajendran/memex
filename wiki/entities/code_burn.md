## Overview
Code Burn is an open-source GitHub repository and tool that provides developers with a local dashboard to track their AI token usage. It helps visualise which projects, AI models, and types of coding tasks consume the most tokens. It operates locally, ensuring user data remains on their machine.

## Role in this knowledge base
The primary subject of the video, presented as a solution for understanding and optimising AI token expenditure.

## Key facts
- It features a 'oneshot rate' metric to gauge AI efficiency on the first try.
