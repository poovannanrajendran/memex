## Overview
Claude Code Setup is an official plugin from Anthropic designed to analyse a user's codebase. It provides recommendations for the most suitable hooks, skills, sub-agents, and server configurations for the specific project.

## Role in this knowledge base
An official Anthropic plugin that assists in optimising the setup and configuration of Claude Code for individual projects.
