## Overview
OmniRoute is a plugin for Claude Code that expands its capabilities by connecting to over 300 different API providers. This allows for continuous usage even when the primary model hits its limits, by seamlessly switching to alternative models.

## Role in this knowledge base
A plugin that enhances Claude Code by providing unlimited usage and access to a vast network of AI models.

## Key facts
- It can offer up to 1.6 billion free tokens by utilising alternative API providers.
