## Overview
agentDir refers to the on-disk state directory for an individual agent within OpenClaw. It resides at ~/.openclaw/agents/<agentId>/ and holds the agent's configuration, authentication profiles, model registry, and other persistent data.

## Role in this knowledge base
Represents the persistent storage location for an individual agent's state.

## Key facts
- It stores per-agent configuration, authentication profiles, and model registry.
