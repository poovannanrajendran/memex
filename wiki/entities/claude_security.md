## Overview
Claude Security is an official security scanner plugin from Anthropic. It scans codebases to identify vulnerabilities and assists users in fixing them, thereby preventing potential exploits by hackers.

## Role in this knowledge base
An official Anthropic plugin focused on enhancing the security of codebases developed with Claude Code.

## Key facts
- It helps to fix security vulnerabilities in code before they can be exploited.
