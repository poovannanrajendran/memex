## Overview
Caveman is a plugin for Claude Code that alters its communication style to be extremely direct and concise, removing all pleasantries and filler words. This aims to reduce token usage while conveying the necessary information for code generation.

## Role in this knowledge base
A plugin that optimises Claude Code's output for efficiency and conciseness.

## Key facts
- It makes Claude talk like a caveman to eliminate filler words and reduce token count.
