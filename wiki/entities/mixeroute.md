## Overview
Mixeroute is an API aggregator that connects users to over 250 AI models, including those from GPT, Gemini, DeepSeek, and Kimiko. It aims to reduce costs by intelligently routing tasks to the most cost-effective models and automatically switching providers if issues arise, all with zero markup.

## Role in this knowledge base
A cost-saving tool that optimises AI model selection and usage for Claude Code and other AI models.

## Key facts
