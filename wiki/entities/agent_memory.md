## Overview
Agent Memory is a free tool that adds persistent memory functionality to AI coding assistants like Claude Code. It automatically records and stores interactions, code changes, and testing results, allowing the AI to recall past information across sessions.

## Role in this knowledge base
The central subject of the video, providing the memory system for AI coding tools.

## Key facts
- It saves interactions into a searchable memory that the AI can reference later, reducing token usage and improving efficiency.
