## Overview
Remotion is a tool for creating videos from code, similar in principle to Claude Motion. It processes video locally on the user's computer and requires Claude Code to run.

## Role in this knowledge base
Presented as an alternative tool for creating code-based animations, especially for users who do not have access to Claude Motion.

## Key facts
- Remotion uses the user's local machine for video processing, unlike Claude Motion which uses the cloud.
