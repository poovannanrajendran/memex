## Definition
Codebase scanning is the process of analysing source code to identify various attributes, such as potential errors, vulnerabilities, code smells, or to understand its structure and dependencies.

## Why it matters (in Poovi's context)
Essential for maintaining code quality, security, and performance. Plugins like Claude Code Setup and Claude Security use this process to offer optimisations and identify risks.

## Key properties or components
- Automated analysis of source code
- Identification of vulnerabilities
- Detection of code smells
- Assessment of code structure
