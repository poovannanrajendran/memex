## Definition
This is a method where an AI system generates code (e.g., JavaScript, Python) that describes and controls the animation process, including elements, timing, colours, and movements. This contrasts with pixel-based generation, where each frame is rendered individually.

## Why it matters (in Poovi's context)
It allows for precise control and easy modification of animation components after they have been generated, making the output more flexible and user-editable than traditional AI video generation.

## Key properties or components
- Creates executable code
- Enables precise control over animation
- Facilitates easy editing of elements
- Separates content from rendering
- Requires an interpreter or runtime environment
