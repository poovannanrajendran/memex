## Definition
Software applications specifically designed and built to run on Apple's macOS operating system, utilising its unique frameworks, APIs, and user interface guidelines. These applications typically offer optimal performance, integration, and user experience within the Apple ecosystem.

## Why it matters (in Poovi's context)
The video emphasises building native apps for better performance, privacy, and a familiar user experience on Macs, contrasting them with cross-platform or web-based solutions that might be less integrated or efficient.

## Key properties or components
- Optimised performance
- Seamless integration with macOS features
- Adherence to Apple's Human Interface Guidelines
- Written in languages like Swift or Objective-C
