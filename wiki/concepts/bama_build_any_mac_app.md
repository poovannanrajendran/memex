## Definition
A methodology and associated set of AI skills, packaged for use with AI coding assistants like Claude, that enables the development of native macOS applications. It aims to democratise app development by allowing users to describe their desired application and have the AI build it.

## Why it matters (in Poovi's context)
This concept is central to the video, as it provides a practical and accessible method for individuals to create custom software solutions for their macOS devices, bypassing traditional development hurdles.

## Key properties or components
- AI-driven development process
- Focus on native macOS applications
- Extends reverse engineering capabilities
- Structured skills for AI agents
- Covers ideation, planning, coding, design, and shipping

## Contradictions or debates
The claims of building 'any' Mac app might be an overstatement, as complex applications requiring deep system integration or highly specialised hardware interaction could still pose challenges for current AI models.
