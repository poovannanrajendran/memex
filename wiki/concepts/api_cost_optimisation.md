## Definition
This refers to strategies and techniques employed to reduce the expenses associated with using Application Programming Interfaces (APIs), particularly for AI models where usage can be costly.

## Why it matters (in Poovi's context)
Rufflow's claimed 75% cost reduction is a significant selling point, addressing a major concern for users of AI services. This optimisation is achieved by using cheaper models for simpler tasks and reserving expensive models for complex ones.

## Key properties or components
- Tiered model usage
- Task routing
- Cost-benefit analysis
- Efficiency improvements
