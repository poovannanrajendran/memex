## Definition
In the context of AI agents, collective memory refers to a shared repository of information, experiences, and learnings that multiple agents can access and contribute to. This allows the system as a whole to improve over time.

## Why it matters (in Poovi's context)
Enables Rufflow's agents to learn from past runs, leading to continuous improvement and increased efficiency in future tasks.

## Key properties or components
- Shared information
- Learning from experience
- System-wide improvement
- Data persistence
