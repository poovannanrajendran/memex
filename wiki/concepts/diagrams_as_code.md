## Definition
Diagrams as Code (DaC) is a methodology where diagrams are created and versioned using code or text-based descriptions. This approach allows for automated generation, easy modification, and integration with software development workflows.

## Why it matters (in Poovi's context)
Enables AI models like Claude to generate complex visualisations programmatically, streamlining technical documentation and communication processes.

## Key properties or components
- Text-based definitions
- Automated generation
- Version control
- Integration with CI/CD pipelines

## Contradictions or debates
Can have a steeper learning curve for non-technical users compared to traditional graphical tools.
