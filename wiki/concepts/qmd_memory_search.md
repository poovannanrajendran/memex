## Definition
QMD (likely Query-based Memory Dialogue or similar) memory search refers to the capability for an agent to search through its own or other agents' session transcripts. This is configured via extra collections in agent settings.

## Why it matters (in Poovi's context)
Enables agents to recall and utilise information from past conversations, potentially across different agents, to inform current responses. It enhances contextual awareness and memory recall.

## Key properties or components
- Searches session transcripts
- Can search other agents' transcripts
- Configured via extraCollections
- Supports cross-agent recall
