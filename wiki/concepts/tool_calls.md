## Definition
Tool calls are a mechanism by which AI models can invoke external functions or tools to extend their capabilities beyond their intrinsic knowledge. This allows them to perform actions like searching the web, running code, or interacting with APIs.

## Why it matters (in Poovi's context)
Tool calls are essential for agentic AI systems like Claude Code to perform practical tasks. They enable the AI to interact with the real world and execute specific programming functions.

## Key properties or components
- Function Invocation
- API Interaction
- External Execution
- Actionable AI
