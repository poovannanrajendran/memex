## Definition
The practice of carefully crafting text prompts to guide AI models, like Claude, to generate specific game systems, behaviours, or code snippets.

## Why it matters (in Poovi's context)
Effective prompt engineering is key to harnessing the power of LLMs for game development, allowing for the creation of diverse game mechanics like movement, timers, or shop systems through natural language instructions.

## Key properties or components
- Clear Instructions
- Contextual Information
- Iterative Refinement
- Specificity
