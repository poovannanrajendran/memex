## Definition
In the context of AI, 'token burn' refers to the consumption of tokens, which are the fundamental units of text that AI models process. This consumption directly relates to the cost of using AI services, as providers often charge based on the number of tokens processed.

## Why it matters (in Poovi's context)
Understanding token burn is crucial for developers and organisations using AI coding tools like Claude, as it directly impacts operational costs and resource management. Tools like Code Burn aim to make this consumption transparent.

## Key properties or components
- Cost implication
- Usage tracking
- Resource management
- AI model processing units
