## Definition
A comprehensive set of standards, guidelines, and reusable components used to create and maintain a consistent look, feel, and functionality across an application or suite of applications. It ensures visual and interactive coherence.

## Why it matters (in Poovi's context)
The BAMA repository includes a feature to automatically generate a design system from existing applications, enabling AI to replicate or derive specific design aesthetics for new apps, thereby improving UI consistency and quality.

## Key properties or components
- UI component library
- Style guides (colours, typography, spacing)
- Brand consistency
- Accessibility guidelines
- Design principles
