## Definition
A command-line interface is a text-based way of interacting with a computer program or operating system. Users type commands to execute tasks, and the program responds with text output.

## Why it matters (in Poovi's context)
CLIs are powerful tools for automation and efficiency, allowing users to control software and perform complex tasks with precise commands.

## Key properties or components
- Text-based commands
- Scriptability
- Automation
- Efficiency
