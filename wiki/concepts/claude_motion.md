## Definition
Claude Motion is a feature within the AI assistant Claude that generates animations from text prompts. It works by producing code that defines the animation's parameters rather than rendering pixels directly.

## Why it matters (in Poovi's context)
It offers a novel way to create editable animations, bridging the gap between simple text-to-video tools and complex animation software, and is particularly relevant for content creation and rapid prototyping.

## Key properties or components
- Prompt-based animation generation
- Code-based output
- Editable elements (text, shapes, images)
- Cloud processing
- Available on Team/Enterprise plans

## Contradictions or debates
While it animates various elements, it cannot create realistic photos or videos.
