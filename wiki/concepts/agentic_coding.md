## Definition
Agentic coding refers to the practice of using AI agents that can autonomously perform coding tasks. These agents can understand instructions, plan actions, and execute code, often with the goal of assisting or automating software development processes.

## Why it matters (in Poovi's context)
It represents a shift towards more intelligent and automated software development, allowing AI to play a more active role in the coding lifecycle.

## Key properties or components
- Autonomy
- Task Planning
- Code Execution
- Tool Use
