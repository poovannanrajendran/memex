## Definition
The Gateway is OpenClaw's central component that hosts and orchestrates multiple isolated agents. It manages their lifecycles, states, and facilitates the routing of messages to the correct agent based on configured bindings.

## Why it matters (in Poovi's context)
The Gateway is the core infrastructure that enables the multi-agent system. It provides the runtime environment and management layer for all hosted agents.

## Key properties or components
- Hosts multiple agents
- Manages agent states
- Routes messages via bindings
- Supports single or multiple agent configurations
