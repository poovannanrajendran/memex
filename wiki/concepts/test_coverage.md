## Definition
Test coverage is a metric used in software testing that describes the degree to which the source code of a program is executed during testing. Higher coverage generally indicates more thorough testing.

## Why it matters (in Poovi's context)
ECC aims to achieve a specific benchmark of 80% test coverage, suggesting a focus on quality and reliability in the code it generates.

## Key properties or components
- Metric
- Code Execution
- Testing Thoroughness
