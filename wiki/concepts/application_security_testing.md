## Definition
Application security testing (AST) involves verifying that an application is free from security vulnerabilities. This includes methods like static analysis, dynamic analysis, and penetration testing.

## Why it matters (in Poovi's context)
ECC incorporates security testing by running its own attacks to identify and fix vulnerabilities early in the development process.

## Key properties or components
- Vulnerability detection
- Penetration testing
- Static analysis
- Dynamic analysis
- Security hardening
