## Definition
Shared memory systems for AI agents allow multiple agents to access and contribute to a common repository of information, context, and learned preferences. This enables better coordination, consistency, and efficiency among agents.

## Why it matters (in Poovi's context)
The video emphasizes that Hermes Agent and other agents share a 'Honcho memory', which is crucial for their integrated functionality and learning user preferences across different interactions.

## Key properties or components
- Information sharing
- Context persistence
- Learning transfer
- Inter-agent coordination
