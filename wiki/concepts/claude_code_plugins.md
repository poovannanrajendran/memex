## Definition
Plugins are extensions or add-ons that enhance the functionality of Claude Code, an AI model designed for coding tasks. These plugins can provide new features, integrate with external services, or modify the AI's behaviour.

## Why it matters (in Poovi's context)
Crucial for extending the capabilities of Claude Code beyond its core functions, enabling specialised tasks like advanced code analysis, team simulation, and enhanced security.

## Key properties or components
- Enhance functionality
- Integrate external services
- Modify AI behaviour
- Specialised tasks
