## Definition
The process by which a system interprets spoken language to understand and execute commands. This involves speech recognition, natural language understanding, and action mapping.

## Why it matters (in Poovi's context)
Enables hands-free operation of tools and systems, enhancing user convenience and accessibility, particularly relevant for AI-driven productivity tools like Jev.

## Key properties or components
- Speech Recognition
- Natural Language Understanding (NLU)
- Intent Recognition
- Entity Extraction
- Action Mapping
