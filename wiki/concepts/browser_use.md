## Definition
Browser use for AI agents refers to the ability of an agent to interact with web browsers, including opening pages, navigating, clicking links, and extracting information, autonomously.

## Why it matters (in Poovi's context)
Enables agents to perform real-world tasks that require accessing and processing information from the internet, expanding their utility beyond pre-defined datasets.

## Key properties or components
- Web navigation
- Element interaction
- Data extraction
