## Definition
Code coverage is a metric used in software testing that measures the percentage of source code that is executed by a test suite. Higher coverage generally indicates more thorough testing.

## Why it matters (in Poovi's context)
ECC aims to achieve a high code coverage of 80%, suggesting a commitment to robust quality assurance in its automated testing process.

## Key properties or components
- Percentage of code executed
- Test suite effectiveness
- Quality metric
- Lines, branches, functions covered
