## Definition
A method of creating animations where the visual elements, timing, and movements are defined by written code rather than manual frame-by-frame drawing or direct manipulation in a visual editor.

## Why it matters (in Poovi's context)
Offers precise control, scalability, and versioning for complex animations. Tools like Claude Motion and Remotion leverage this to allow users to edit animations by modifying code.

## Key properties or components
- Programmatic control over visuals
- Temporal precision
- Repeatability and scalability
- Version control
- Requires programming knowledge or AI assistance

## Contradictions or debates
Can have a steeper learning curve compared to visual tools for non-programmers. Debugging complex code-based animations can be challenging.
