## Summary
The Microsoft Agent Framework is a new platform for building AI applications, merging the capabilities of Microsoft AutoGen and Semantic Kernel. It provides individual agents that use LLMs for various tasks and graph-based workflows for orchestrating multi-step processes. The framework aims to offer developers a flexible and robust environment for creating interactive and safe AI solutions.

## Key claims
- The Microsoft Agent Framework integrates the strengths of Microsoft AutoGen and Semantic Kernel.
- It offers two main components: individual Agents for LLM-powered tasks and Workflows for orchestrating multi-step processes.
- The framework supports a wide range of LLM providers, including Microsoft Foundry, Anthropic, Azure OpenAI, OpenAI, and Ollama.
- Agent Framework introduces explicit control over multi-agent execution paths via workflows and robust state management for long-running or human-in-the-loop scenarios.
- It is positioned as the next generation of both Semantic Kernel and AutoGen.

- [[workflows]] — Workflows provide the orchestration layer in the Microsoft Agent Framework, enabling complex, multi-agent tasks to be executed in a controlled and structured manner. They are crucial for managing long-running processes and incorporating human oversight.
- [[large_language_models_llms]] — LLMs are fundamental to the Microsoft Agent Framework, powering the decision-making and response generation capabilities of individual agents. The framework's ability to connect with various LLM providers enhances its versatility.
