## Summary
This YouTube video outlines a 10-day plan to learn AI agents, focusing on practical application over theoretical knowledge. It recommends starting with the "Awesome LLM Apps" GitHub repository for working agent examples, followed by Microsoft's "AI agents for beginners" for guided lessons. The plan also includes using CrewAI for multi-agent system development and LangGraph for understanding orchestration and state management in production workflows. Finally, it suggests studying OpenHands to see autonomous coding agents in action, emphasising that building and learning publicly is key to success in AI agents.

## Key claims
- A 10-day plan for learning AI agents can be achieved through a curated set of GitHub repositories and tools.
- Practical building and experimentation are more crucial for success with AI agents than deep theoretical knowledge.
- Awesome LLM Apps, Microsoft's AI agents for beginners, CrewAI, LangGraph, and OpenHands are key resources for learning AI agents.
- CrewAI enables the creation of multi-agent systems within hours and is utilised by a significant portion of Fortune 500 companies.
- LangGraph is essential for understanding the orchestration and state management of production agent workflows.
- OpenHands demonstrates an autonomous coding agent performing real work.
- Success in AI agents comes from building, breaking, shipping, and learning in public.
