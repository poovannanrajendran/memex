## Summary
This YouTube video introduces a viral GitHub repository called 'Code Burn' that helps developers track and understand their AI token consumption when using tools like Claude for coding. The open-source, MIT-licensed tool provides a local dashboard within the terminal, detailing token usage by project, AI model, and work type. A key feature highlighted is the 'oneshot rate', which measures how often the AI successfully completes a task on the first attempt.

## Key claims
- The 'Code Burn' GitHub repository helps developers track AI token usage.
- It provides a local dashboard in the terminal to visualise AI coding expenses.
- The tool identifies which projects and AI models consume the most tokens.
- 'Oneshot rate' is a feature that measures the AI's success rate on the first try.
- Code Burn is open-source and MIT licensed.
- The tool reads AI coding session data locally, ensuring user data remains on their machine.

## Concepts covered
- [[token_burn]] — Understanding token burn is crucial for developers and organisations using AI coding tools like Claude, as it directly impacts operational costs and resource management. Tools like Code Burn aim to make this consumption transparent.
- [[oneshot_rate]] — This metric is important for evaluating the efficiency and accuracy of AI coding agents. A higher oneshot rate suggests a more effective and less costly AI, as it reduces the need for iterative prompting and problem-solving, thereby saving tokens and developer time.
