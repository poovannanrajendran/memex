## Summary
This YouTube video introduces a viral open-source GitHub repository called 'Code Burn' that helps developers track and understand their AI token usage, specifically with tools like Claude. The repository provides a local dashboard within the terminal to visualise which projects, AI models, and types of work are consuming the most tokens. A key feature highlighted is the 'oneshot rate', which measures how often an AI successfully completes a task on the first attempt.

## Key claims
- The Code Burn GitHub repository helps developers track AI token consumption.
- Code Burn provides a local, open-source dashboard for visualising AI usage.
- The tool identifies which projects and AI models are using the most tokens.
- Code Burn introduces the 'oneshot rate' metric to measure AI first-attempt success.
- The repository is useful for developers using AI coding agents like Claude.
