## Summary
Google has open-sourced Harness Squared, a tool designed to automatically improve AI agents without the need for retraining. It works by running the agent, proposing and testing edits to its configuration, and implementing those that show improvement. This process allows agents to learn and adapt, becoming better at improving themselves over time. The tool efficiently uses a combination of cheaper and more advanced AI models.

## Key claims
- Harness Squared is a new open-source tool from Google.
- It enables AI agents to upgrade themselves without retraining.
- The tool automatically proposes, tests, and applies edits to agent configurations.
- Harness Squared can significantly improve agent performance, with Google's tests showing up to an 11.5-point score increase in one round.
- The system learns from tasks, enabling agents to improve their own improvement capabilities.
- It efficiently combines cheaper models for task execution and frontier models for upgrades.
