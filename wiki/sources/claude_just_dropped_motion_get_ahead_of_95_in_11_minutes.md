## Summary
This video introduces Claude Motion, a new tool from Anthropic that generates animations directly from text prompts within the Claude interface. Unlike traditional AI video generators that create pixels, Claude Motion writes code, allowing for easy editing of individual elements like text, shapes, and images. The presenter demonstrates its capabilities by creating a stop-motion style commercial and explains how to integrate it with tools like Higgs Field for a more premium look. For users without direct access to Claude Motion, an alternative using Claude Code and Remotion is also presented.

## Key claims
- Claude Motion turns a text prompt into an animation.
- Claude Motion works by generating code rather than pixels, allowing for granular editing of video elements.
- Users can directly edit text, adjust scene duration, animation speed, and even modify visual elements by providing new instructions.
- Claude Motion integrates with other tools like Higgs Field to achieve a more polished and professional visual output.
- For users not on Claude Motion-compatible plans, Remotion combined with Claude Code offers a similar code-based animation capability.
- Claude Motion is currently available on Team and Enterprise plans within Claude.
