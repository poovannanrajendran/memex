## Summary
This YouTube video introduces Vibewise, a free plugin designed to enhance developer learning when using AI coding assistants like Claude. Unlike traditional AI coding that can lead to reduced understanding, Vibewise prompts users with questions about their design choices, explains trade-offs, and details code modifications. This ensures that developers actively learn from the AI-generated code, improving comprehension and knowledge retention.

## Key claims
- Developers who code with AI may not learn as effectively about the code they produce.
- Asking AI questions during the coding process significantly improves learning.
- Vibewise is a free plugin that automates the process of asking clarifying questions to AI coding assistants.
- Vibewise prompts users about their design, discusses trade-offs, and explains code changes before and during AI code generation.
- The plugin enhances learning without sacrificing the speed or convenience of AI-assisted coding.
- Vibewise is compatible with Claude Code and Codex.
