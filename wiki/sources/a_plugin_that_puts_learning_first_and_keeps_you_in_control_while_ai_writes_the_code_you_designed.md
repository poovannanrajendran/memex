## Summary
This YouTube video introduces Vibewise, a free plugin designed to enhance developer learning when using AI coding assistants like Claude. It addresses the risk of reduced learning from direct AI code generation by making the AI actively engage the user in the design process, posing questions about their approach, discussing trade-offs, and explaining modifications. The plugin aims to ensure developers still learn while benefiting from AI assistance.

## Key claims
- Coding directly with AI can lead to developers scoring lower on comprehension quizzes about the code they wrote.
- Developers who actively question AI while coding learn significantly more.
- Vibewise is a free plugin that automates the process of AI asking developers questions and explaining code.
- Vibewise prompts the AI to ask about the developer's preferred method, discuss trade-offs, and explain changes before writing code.
- The plugin works with Claude Code and Codex, facilitating learning alongside AI-assisted coding.
