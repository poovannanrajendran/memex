## Summary
UI-TARS is a free AI agent developed by ByteDance, the creators of TikTok. It can automate tasks on a computer by observing the screen, controlling the mouse, and interacting with applications as if a human were performing the actions. It operates locally on the user's machine, ensuring data privacy, and supports both Mac and Windows operating systems.

## Key claims
- UI-TARS is a highly underrated AI tool for 2026.
- It is developed by ByteDance.
- UI-TARS can automate tasks by mimicking human interaction with the computer interface (seeing screen, moving mouse, clicking, filling forms).
- It runs locally on the user's machine, keeping data private.
- It has built-in computer and browser control modes.
- It is free and requires no coding.
- It is compatible with Mac and Windows.
