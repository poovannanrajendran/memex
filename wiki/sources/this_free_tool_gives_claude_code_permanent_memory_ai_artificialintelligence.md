## Summary
A new free tool called Agent Memory has been developed to provide Claude Code and other AI coding tools with persistent memory. This addresses the common issue of AI forgetting project context, setup, and previous solutions each time a session is closed. Agent Memory automatically saves interactions, tool usage, edits, tests, and errors into a searchable database, allowing the AI to recall past fixes and information, thus improving efficiency and reducing repetitive mistakes.

## Key claims
- Agent Memory provides AI coding tools with permanent memory.
- It solves the problem of AI forgetting context between sessions.
- The tool saves interactions, tool use, edits, tests, and errors automatically.
- It uses less tokens compared to re-explaining everything in chat.
- Agent Memory works with Claude Code, Cursor, Codex, Windsurf, and any NPX tool.
- It automatically replaces old memories with new information to avoid confusion.
- The tool hides API keys and secrets before saving.
- It can be installed with a single command: `npx agent-memory`.
